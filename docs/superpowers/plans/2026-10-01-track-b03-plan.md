**Goal:** Replace the astronaut illustration in `HeroSection.vue` with an inline ocean-themed SVG component (`OceanHero.vue`, ≤ 4 KB) that fits the ReduCera ocean theme and respects `prefers-reduced-motion`.

**Architecture:** Pure inline SVG component using Nuxt UI semantic color tokens (`currentColor`, `var(--rc-primary)`, `var(--rc-secondary)`, `var(--rc-accent)`). Animation via SVG `<animate>` primitives and Tailwind `motion-safe` / `motion-reduce` variants. No JS, no external assets.

**Tech Stack:** Vue 3 SFC, Nuxt 4, Tailwind CSS (motion-safe variants), `@nuxt/image` (no longer used in `HeroSection.vue`).

```vue

    <rect x="0" y="0" width="400" height="400" fill="url(#caustic)" />
```
