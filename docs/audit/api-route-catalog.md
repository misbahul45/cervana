# 4. Route red flags (master prompt §52)

The static catalog was scanned for the master-prompt §52 anti-patterns. Findings are recorded in [`api-business-logic-audit.md`](./api-business-logic-audit.md) §3; the most severe are:

| Finding | Severity | Location |
|---|---|---|
| `PATCH` on quiz attempts accepts `score` and `status` from the client | **CRITICAL** | `services/api/src/v1/quiz/quiz-attempts/quiz-attempts.controller.ts:39` + DTO `quizAttempets.dto.ts:13-16` |
| `POST` and `PATCH` on answers accept `isCorrect` and `pointsEarned` from the client | **CRITICAL** | `services/api/src/v1/quiz/answers/answers.controller.ts:13-38` + DTO `answers.dto.ts:6-12` |
| Reservation in `ai-credits.service.ts` reads wallet, computes available, then updates wallet in two non-atomic steps with no row lock | **HIGH** | `services/api/src/v1/ai-credits/ai-credits.service.ts:55-77` |

These and all other red flags are listed in `api-business-logic-audit.md` §3 with the full master-prompt §90 record format.
